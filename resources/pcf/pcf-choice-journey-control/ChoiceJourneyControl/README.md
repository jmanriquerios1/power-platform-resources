# ChoiceJourneyControl

PCF independiente para mostrar opciones tipo Choice como un journey/stepper visual.

## Estructura
- `models/`: tipos del dominio
- `services/`: lógica de resolución y estilos
- `hooks/`: extracción de opciones
- `components/`: UI React
- `styles/`: CSS del control
- `tests/`: pruebas

## Scripts
- `npm run build`
- `npm run lint`
- `npm run test`

## Notas
Basado en la convención del repositorio y sin modificar `Choice Color Tiles`.
